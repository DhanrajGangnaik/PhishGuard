Project Overview

About PhishGuard

A laptop-runnable phishing detection project designed for academic demonstration, container deployment, and explainable cybersecurity analysis.

What It Does

Key Features

  • Analyzes suspicious URLs and email content locally.
  • Produces Safe, Suspicious, or Phishing classifications.
  • Explains the decision using triggered reasons and extracted features.
  • Stores scan history in SQLite for later review.
  • Displays dashboard charts for demo-ready presentation.

Stack

Technology Used

  • Backend: Flask + Python
  • Frontend: HTML, CSS, JavaScript
  • Charts: Chart.js
  • Database: SQLite
  • Deployment: Docker container with Gunicorn
